# نظام هياكل التحميل المتطورة لبطاقات وجداول المنتجات (Advanced Product Loading Skeletons)

تطوير منظومة هياكل تحميل ذكية ومتجاوبة داخل حاوية البيانات وبطاقات المنتجات لتقليل الإحساس بزمن الاستجابة أثناء جلب البيانات الأولية أو تحميل الدفعات المتتابعة من قاعدة بيانات Supabase، مع انتقال بصري سلس يتماشى مع الهوية البنفسجية الملكية لمتجر أحمد بحري.

---

## قرارات التصميم المعتمدة (Confirmed User Decisions)

> [!IMPORTANT]
> تم اعتماد التفضيلات التالية بناءً على إجاباتك لتوجيه التصميم والتنفيذ الهندسي:

- **التصميم البصري وحركة التحميل**: وميض متدرج بنفسجي ملكي (`#2e1065` -> `#4c1d95` -> `#5b21b6`) يحاكي تفاصيل بطاقة المنتج والجدول بدقة (مصغرة الصورة، العنوان، القسم، الأسعار، المخزون، وأزرار الإجراءات).
- **التكيف التلقائي عبر الشاشات**: استجابة تلقائية تعرض هياكل بطاقات المنتجات الكاملة على شاشات الهواتف والأجهزة اللوحية، وصفوف جداول متناسقة مع أعمدة البيانات على شاشات الحاسوب.
- **الربط الذكي بحالة الجلب والانتقال السلس**: ارتباط تلقائي بحالة الجلب الأولية من سياق البيانات (`DataContext`) وحالة جلب الدفعات الإضافية عند التمرير، مع انتقال تدريجي سلس (`opacity` & `transform` fade-in) فور وصول البيانات دون أي إزاحة في التخطيط (Zero CLS).

---

## 1. نظرة عامة والقيمة المضافة (Overview & Core Value)

- **ما الذي يقدمه التحديث**: يحول `DataTableWrapper` من مجرد غلاف للتمرير الأفقي بالسحب إلى حاوية عرض ذكية تدرك حالة تحميل البيانات والدفعات، وتقدم هياكل تحميل (Skeletons) تحاكي أبعاد البطاقات والصفوف الفعلية بنسبة تطابق هندسي كاملة.
- **المستفيدون**: مديرو المتجر والموظفون في لوحة التحكم (صفحات المنتجات، المخزون، وسجل الجرد) وزوار الواجهة عند استعراض قوائم المنتجات الكبيرة.
- **الأثر المباشر**:
  - القضاء على ظهور رسالة «لا توجد منتجات بعد» بشكل مؤقت وخاطئ أثناء الاتصال الأولي بـ Supabase.
  - تقليص الإحساس النفسي بزمن التحميل (Perceived Latency) عبر إظهار بنية الصفحة فوراً قبل اكتمال وصول الحزم الشبكية.

---

## 2. تجربة المستخدم والهوية البصرية (User Experience & Visual Design)

- **مسار تجربة المستخدم (User Flow)**:
  1. **لحظة فتح الصفحة أو بدء الجلب**: يظهر هيكل التحميل فوراً بنفس أبعاد البطاقات (في الجوال) أو صفوف الجدول (في الحاسوب) مع شريط حالة علوي هادئ يوضح جريان مزامنة البيانات.
  2. **أثناء التمرير السريع وتحميل الدفعات (Chunked Pagination)**: تظهر هياكل بطاقات/صفوف إضافية في أسفل القائمة تحجز المساحة مسبقاً وتمنع قفز المؤشر أو اهتزاز الصفحة.
  3. **لحظة وصول البيانات من Supabase**: تتلاشى الهياكل وتظهر البطاقات الحقيقية بحركة انسيابية سريعة (`150ms–200ms`) مع الحفاظ على محاذاة الأرقام (`tabular-nums`).
- **الهوية اللونية والوميض (Royal Purple Shimmer)**:
  - استخدام تدرج متحرك ناعم يجمع بين درجات البنفسجي الداكن والملكي (`#1e1136`، `#3b1774`، `#5b21b6/40`) في الوضع الداكن، وتدرجات بنفسجية فاتحة متزنة في الوضع النهاري، مع احترام تفضيلات تقليل الحركة (`prefers-reduced-motion`).
- **التطابق الهندسي (Geometry Matching)**:
  - **هيكل بطاقة الجوال (Mobile Product Card Skeleton)**: يحاكي رأس البطاقة (مربع الاختيار، اسم المنتج، شارة القسم وحالة التوفر)، وإطار الصورة المربعة في المنتصف (`64×64px`)، وشبكة الأسعار والكميات المكونة من عمودين، وأزرار الإجراءات السفلية.
  - **هيكل صف الحاسوب (Desktop Table Row Skeleton)**: يحاكي أعمدة الجدول (مربع الاختيار، مصغرة الصورة مع اسم المنتج والوصف، شارة القسم، التكلفة، الجملة، نسبة الربح، سعر المفرد، الكمية، المورد، وعمود الإجراءات المثبت).

---

## 3. القرارات الهندسية والمفاضلات (Key Product Decisions & Trade-Offs)

- **القرار 1: دمج الذكاء التلقائي في الحاوية مع دعم التخصيص الاختياري**
  - *النهج المختار*: قراءة حالة التحميل تلقائياً من سياق البيانات العام مع إتاحة خصائص اختيارية (`isLoading`, `isLoadingMore`, `skeletonCount`, `variant`) للتحكم الدقيق عند الحاجة.
  - *السبب*: يضمن تفعيل هياكل التحميل تلقائياً في كافة جداول وبطاقات لوحة التحكم دون الحاجة لتكرار الشفرة في كل صفحة، مع مرونة كاملة لتخصيص عدد الصفوف أو شكل البطاقة.
- **القرار 2: الاعتماد على خصائص المعالج الرسومي فقط في الحركة (`Compositor-Only Animations`)**
  - *النهج المختار*: تنفيذ تأثير الوميض والظهور التدريجي باستخدام `opacity` و `transform` حصرياً دون تحريك أبعاد العناصر (`width`/`height`).
  - *السبب*: ضمان سرعة إطارات 60fps على الهواتف المتوسطة ومنع أي إعادة حساب مكلفة لتخطيط الصفحة (Layout Thrashing).

## 4. البنية المعمارية وتدفق الحالة (Technical Architecture & State Flow)

```
┌────────────────────────────────────────────────────────────────────────────┐
│                   Supabase & DataContext / Pagination Hook                 │
│     (loading: boolean, isLoadingMore / hasMore, visibleProducts[])         │
└─────────────────────────────────────┬──────────────────────────────────────┘
                                      │
                                      ▼
┌────────────────────────────────────────────────────────────────────────────┐
│                    DataTableWrapper (Smart Container)                      │
│  • Auto-detects initial loading & batch pagination states                  │
│  • Preserves horizontal drag-to-scroll & touch pan ergonomics              │
├─────────────────────────────────────┬──────────────────────────────────────┤
│     Initial Fetch (loading=true)    │    Data Ready (loading=false)        │
│                 │                   │                 │                    │
│                 ▼                   │                 ▼                    │
│  ┌───────────────────────────────┐  │  ┌────────────────────────────────┐  │
│  │   Responsive Skeleton Engine  │  │  │  Smooth Fade-In Content Layer  │  │
│  ├───────────────┬───────────────┤  │  ├────────────────┬───────────────┤  │
│  │ Desktop (>=md)│ Mobile (<md)  │  │  │ Desktop Table  │ Mobile Cards  │  │
│  │ Table Header +│ Product Card  │  │  │ + Drag Scroll  │ + Quick Edit  │  │
│  │ Shimmer Rows  │ Shimmer Grid  │  │  └────────┬───────┴───────┬───────┘  │
│  └───────────────┴───────────────┘  │           │               │          │
│                                     │           ▼               ▼          │
│                                     │  ┌────────────────────────────────┐  │
│                                     │  │ Bottom Batch Skeleton Append   │  │
│                                     │  │ (Shown during chunk prefetch)  │  │
│                                     │  └────────────────────────────────┘  │
└─────────────────────────────────────┴──────────────────────────────────────┘
```

### تفاعل المكونات وإدارة الحالة:
- **حالة التحميل الأولي (`Initial Loading`)**: عندما تكون البيانات قيد الجلب من Supabase وتكون القائمة فارغة، يعرض `DataTableWrapper` (أو قسم البطاقات المرتبط به) هياكل التحميل المتجاوبة فوراً بدلاً من شاشة «لا توجد منتجات».
- **حالة الجلب التدريجي للدفعات (`Batch Prefetching`)**: عند اقتراب المستخدم من نهاية القائمة وتفعيل جلب الدفعة التالية، تُعرض صفوف/بطاقات هيكلية مصغرة أسفل العناصر الحالية حتى تندمج الدفعة الجديدة بسلاسة.
- **حالة استقرار البيانات (`Populated / Empty State`)**: فور انتهاء التحميل، تظهر المنتجات بتأثير تلاشي تدريجي ناعم، ولا تظهر رسالة الحالة الفارغة إلا إذا انتهى الجلب فعلياً وكانت النتيجة صفراً.

# خطة تطوير محرك البحث الذكي فائق السرعة (Smart Fuzzy & Hybrid Search Engine) — متجر أحمد بحري

## 1. نظرة عامة على النظام وتجربة البحث الجديدة
يهدف هذا التحديث إلى استبدال البحث الحرفي البطيء في واجهة المتجر وكافة أقسام لوحة التحكم بمحرك بحث هجين فائق السرعة (Sub-millisecond Hybrid Search Engine) يدعم المطابقة الجزئية والمرنة، يفهم اللهجة العراقية والمصطلحات الفنية لقطع غيار الدراجات والشحن، ويتسامح مع الأخطاء الإملائية واختلاف ترتيب الكلمات، مع تقديم مقترحات ذكية تلقائية عند ندرة النتائج المباشرة، وتزويد قاعدة بيانات Supabase بفهارس `pg_trgm` ودالة بحث ذكية.

---

## 2. القرارات المعتمدة من المستخدم (Confirmed Design Decisions)
1. **الذكاء اللغوي العربي والمرادفات:**
   - **تطبيع الحروف والأرقام تلقائياً:** توحيد الهمزات (`أ، إ، آ، ٱ ← ا`)، التاء المربوطة والهاء (`ة ← ه`)، الألف المقصورة والياء (`ى ← ي`)، إزالة التشكيل والمد (`ـ`)، وتحويل الأرقام العربية الشرقية (`٠-٩`) إلى أرقام قياسية (`0-9`).
   - **قاموس مرادفات قطع الغيار (Iraqi & Arabic Spare-Parts Thesaurus):** ربط تلقائي للمصطلحات المترادفة المتداولة في السوق (مثل: `تاير ↔ إطار ↔ كفر ↔ تيوبلس`، `باتري ↔ بطارية ↔ نضيدة`، `شاحنة ↔ شاحن ↔ جارجر`، `بريك ↔ فرامل ↔ سفايف ↔ دسك`، `بولبرن ↔ رومان ↔ محمل`، `جنط ↔ ويل ↔ رنك`، `كلتش ↔ صحن ↔ فاصل`، `كربريتر ↔ كاربراتير`، `ماطور ↔ محرك ↔ دينمو`، `لايت ↔ شمعة ↔ فانوس ↔ لد`، `صوندة ↔ خرطوم`، `دبل ↔ ماص صدمات ↔ مساعد`).
   - **التسامح مع الأخطاء الإملائية (Fuzzy Typo Tolerance):** خوارزمية تشابه ثلاثية المقاطع (Trigram Similarity) ومسافة التحرير (Levenshtein Distance) لالتقاط الكلمات حتى مع وجود حروف ناقصة أو مبدلة.
2. **عرض النتائج البديلة والتقريبية (Smart Fallback UX):**
   - عرض **المطابقات المباشرة والجزئية أولاً** مرتبة حسب درجة الصلة (Relevance Score).
   - عند انعدام المطابقات المباشرة أو قلّتها، يظهر تلقائياً قسم **"منتجات مشابهة ومقترحة"** يعرض أقرب المنتجات تشابهاً بالاسم أو المرادفات أو القسم دون أن يواجه المستخدم شاشة فارغة مسدودة.
3. **آلية الأداء الفوري وتجربة العرض (Hybrid Search & Highlighting):**
   - **بحث هجين فوري (Zero-Latency Hybrid Search):** فهرسة محلية بالذاكرة تعمل في أجزاء من المللي ثانية لعرض النتائج الفورية أثناء الكتابة دون أي تأخير، مدعومة باستعلام Supabase ذكي ومؤقت (`Debounced 180ms`) لجلب أي بيانات إضافية من السيرفر.
   - **تظليل الكلمات المطابقة (Match Highlighting):** إبراز الكلمات أو المقاطع المطابقة داخل أسماء المنتجات والأكواد بلون المتجر البنفسجي الملكي (`#5b21b6`) لتسهيل المسح البصري السريع.

## 3. الهوية البصرية وتصميم واجهة المستخدم (Visual & UX Architecture)
- **الهوية اللونية لمتجر أحمد بحري:**
  - توحيد كافة عناصر البحث في المتجر ولوحة التحكم باللون البنفسجي الملكي (`#5b21b6` / `#7c3aed`) والخلفيات الداكنة الفاخرة (`#160b2e` و `#241046`) بدلاً من ألوان الأزرق الافتراضية القديمة.
- **شريط البحث المطور وقائمة المقترحات الفورية (Live Search Dropdown):**
  - تصميم متجاوب بالكامل (100% Responsive) على الهواتف والأجهزة اللوحية والحواسيب مع زر مسح سريع (`X`)، ومؤشر عدد النتائج الفوري، وتنقل سلس.
  - تعرض القائمة المنسدلة الفورية صورة مصغرة للمنتج، الاسم مع تظليل الكلمات المطابقة، القسم، السعر، وحالة التوفر، متبوعة بقسم **"منتجات مشابهة ومقترحة"** عند الحاجة.
- **لوحة التحكم (Dashboard Search Across All Sections):**
  - ترقية البحث في **إدارة المنتجات**، **الجرد والمخزون**، **إدارة الأقسام (إضافة منتجات للقسم)**، **الموردين**، **الملصقات الحرارية**، و**نوافذ ربط المنتجات** ليعمل بنفس المحرك الذكي الفوري ويدعم البحث بالاسم، الباركود/الكود الجزئي، الملاحظات، اسم القسم، أو اسم المورد بأي ترتيب كلمات.

## 5. مراحل التنفيذ وقاعدة البيانات (Implementation & Supabase SQL Deliverable)
1. **بناء نواة البحث الذكي الموحدة:**
   - إنشاء محرك التطبيع العربي، محول الأرقام، موسع المرادفات، حساب التشابه الثلاثي (Trigram Similarity)، ومكون تظليل النصوص المطابقة.
2. **تحديث واجهة المتجر (Storefront Search & Suggestions):**
   - ربط شريط البحث في الصفحة الرئيسية وقائمة المقترحات الفورية بالمحرك الهجين مع إزالة طلبات الشبكة المتكررة مع كل حرف، وتطبيق التصميم البنفسجي الفاخر (`#5b21b6`)، وإضافة قسم **"منتجات مشابهة ومقترحة"** التلقائي.
3. **تحديث كافة أقسام لوحة التحكم (Dashboard Search Upgrade):**
   - تعميم البحث الذكي المرن على صفحات المنتجات، المخزون، الأقسام، الموردين، والملصقات الحرارية ليدعم البحث الجزئي والمتعدد الكلمات والأكواد.
4. **تقديم كود SQL الجاهز للنسخ (Supabase SQL Editor Script):**
   - في نهاية رد التنفيذ مباشرة، سيتم إرفاق كود SQL نظيف وجاهز للنسخ (` ```sql `) لتفعيل إضافات `pg_trgm` و `unaccent`، وإنشاء دالة تطبيع الحروف العربية `normalize_arabic_text`، وبناء فهارس GIN الثلاثية السريعة على جدول المنتجات، وإنشاء دالة `search_products_smart` للبحث الهجين والترتيب حسب درجة التشابه.
